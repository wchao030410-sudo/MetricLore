# Metric Query

## 适用场景

回答某个指标在指定日期范围、维度或筛选条件下的事实数值。包括单点值、趋势、期间对比和维度拆分。

## 执行方法

1. 用 `semantic_catalog` 确认指标、维度和别名。
2. 用 `metric_query` 执行受治理查询；工具输入只能是目录中的对象、日期和筛选值。
3. 用户要求期间对比时调用 `compare_periods`；要求拆分时调用 `dimension_breakdown`。
4. 回显实际时间范围、维度、筛选和行数，并调用 `submit_evidence` 绑定查询结果。

## 禁止事项

不得接收或生成任意 SQL；不得用日比率的平均值代替周期比率；不得把查询结果延伸为原因分析。
