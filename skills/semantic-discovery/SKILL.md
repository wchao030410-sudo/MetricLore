# Semantic Discovery

## 适用场景

用户使用别名、模糊业务词或询问“有哪些指标/字段/业务过程”时使用。目标是识别可执行的指标、维度或知识实体，而不是直接猜测一个答案。

## 执行方法

1. 调用 `semantic_catalog` 查找已注册的指标与维度。
2. 调用 `wiki_search` 或 `ontology_neighbors` 补充业务过程、规则和数据资产上下文。
3. 候选唯一时返回推荐对象及其差异；候选不唯一时返回候选列表并要求用户确认。
4. 调用 `submit_evidence` 记录所依据的目录和实体。

## 输出契约

输出候选名称、Key、定义差异和下一步建议。不得把未注册对象作为可执行对象。
