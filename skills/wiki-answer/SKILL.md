# Wiki Answer

## 适用场景

回答指标定义、业务规则、字段语义、数据来源、看板和血缘关系。它不负责计算实时数值，也不负责解释指标变化原因。

## 执行方法

1. 使用 `wiki_search` 召回候选实体；若用户已给出明确实体 Key，可直接使用 `wiki_entity`。
2. 对核心实体调用 `wiki_entity`，读取类型、状态、来源和关系。
3. 用户询问血缘、分子分母或影响范围时，调用 `wiki_trace` 或 `ontology_neighbors`。
4. 使用 `submit_evidence` 将回答中的关键声明绑定到规范实体或来源。

## 输出契约

先直接回答，再列出来源。若实体状态不是 `verified`，必须说明状态；若找不到来源或多个候选无法区分，输出 `not_answerable` 或请求澄清。

## 禁止事项

不得根据常识补全业务事实；不得把字段名称推断成业务口径；不得调用数据查询工具。
