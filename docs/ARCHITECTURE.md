# 架构说明

```text
浏览器
  ├─ 指标目录 / 语义模型 / Wiki 检索
  └─ Agent 问答
          │
          ▼
Node HTTP 服务
  ├─ WikiIndex：Markdown 本地检索与来源定位
  ├─ DataAgent：意图识别、工具选择、证据编排
  ├─ SemanticLayer：指标/维度白名单与参数化 SQL
  ├─ SQLite：合成事实数据
  └─ OpenAI-compatible LLM（可选，仅做有证据表达）
```

## 决策

1. **本地优先**：默认不调用外部服务，没有 API Key 也能运行。
2. **语义层拥有 SQL**：LLM 不生成或执行任意 SQL，只能选择注册指标和维度。
3. **知识与数据分路**：口径问题先查 Wiki，数值问题走指标查询，分析问题在数据结果上做保守描述。
4. **复合指标后聚合计算**：客单价等指标先聚合分子、分母，再相除，避免错误平均。
5. **因果语言受限**：没有额外证据时，只描述变化，不声称找到根因。

## 当前限制

- 只连接一个 SQLite 事实表。
- 自然语言日期识别仅覆盖“近 N 天”等基础表达。
- Wiki 使用本地词项匹配，没有向量索引。
- 没有用户、租户、行列权限与持久化审计。

这些限制让开源演示保持可读和可启动。扩展到生产环境时，可以替换数据库适配器与检索器，但应保留语义白名单和证据边界。
